## 🌐 English Documentation

### Features
* **Dual Format Support:** Download videos as **MP4** (1080p, 720p, 360p) or extract audio as high-quality **MP3** (320k, 256k, 128k).
* **Modern GUI:** Clean, high-DPI aware, and responsive user interface with custom Tkinter styling.
* **Real-Time Progress:** Live tracking of download percentage, speed, and ETA.
* **Portable Architecture:** Works seamlessly alongside `yt-dlp.exe` and `ffmpeg.exe`.
* **Safe Cancellation:** Stop ongoing downloads safely at any moment without leaving background processes.

### Requirements
Ensure the following files are in the **same directory**:
1. `media_downloader.pyw` (or the compiled `.exe`)
2. `yt-dlp.exe`
3. `ffmpeg.exe`
